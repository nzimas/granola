# Airwindows plugins compiled into Granola's performance FX repertoire.
#
# Curated for a granular instrument: every entry must be audible and
# transformative when dropped into a random chain. Deliberately excluded:
#   - Console*/Purest* buss chains (transparent by design — inaudible here)
#   - dither, monitoring, metering, trim, utility
#   - reverbs and delays (the master section already owns those)
#
# Grouped by family so the randomiser can be biased later if a chain of four
# distortions gets tiring.
